# AI Link 0.13.0 验证报告

验证日期：2026-10-22。环境：Windows 11 x64、Python 3.13.7、Node 22.20.0、npm 10.9.3、Electron 45.0.0。

## 干净源码与独立构建

按允许清单重新导出源码，在新虚拟环境与新 node_modules 中安装锁定依赖，从该目录编译 Vue／TypeScript、Python 服务和 Electron。构建不引用旧发行目录、旧虚拟环境或旧版应用状态。依赖管理器可以使用其校验后的下载缓存；这些缓存不进入交付包。npm lockfile 使用官方公共 registry 地址。

源码包仅含源码、锁文件、构建脚本、隔离测试、文档、合成示例截图和图标，不含 .git、依赖目录、编译产物、日志、聊天、账号凭据、个人状态或历史版本。打包脚本拒绝链接文件、疑似 API 密钥与个人机器绝对路径，并生成 CRC 和 SHA-256 校验信息。

受控套接字测试注入主备连接延迟 350／20 ms：顺序连接中位数 353.10 ms，竞速 24.31 ms；6 份预期数据收到 6 份，无隧道请求重放。这是本机路径选择验证，不能解释为真实 VPN 提速比例。

额外验证独立 Codex 进程边界：第二进程无法接管活动写入，不能中止原进程活动回合；拥有者可确认中止，释放后的历史可接入。

三组有计数的 Codex 联调共 46 项，使用 13 次本机模型替身请求；另有进程边界探测。所有生成仅发往隔离本机替身，未消费外部模型额度。账号额度、恢复时间与清理年龄使用测试值；没有改变用户真实对话、账号配置或系统代理。桌面测试使用独立 Electron 配置、应用状态和 CODEX_HOME；调试端口仅为测试临时绑定本机，日常启动不带此端口。

## 可复验入口

安装 requirements-dev.txt 后运行：

```powershell
.\scripts\verify.ps1 -TestCodex
.\build-vue-desktop.ps1 -FreshProfile
.\.venv\Scripts\python.exe tests/smoke_packaged.py
.\.venv\Scripts\python.exe tests/smoke_desktop.py
```

缺少 Codex CLI 时省略 -TestCodex，并在服务检查末尾加 --skip-shared；此时打包检查为 31 项。桌面启动检查临时打开实际应用并自动关闭。GitHub Actions 已配置 Windows 验证、构建与启动流程；本报告记录本机验证结果，远端运行状态见仓库的 Actions 页面。

## 已知边界

- 无法保证 VPN 整体断线时仍有网络，也无法保证第三方应用遵守系统代理。断开的已建隧道需要原 AI 客户端重连。
- 同服务共享控制已通过实际进程验证；未开放接口的独立原生桌面活动对话不能强制接管。
- Plus／Pro 与个人双窗口规则通过隔离测试；真实 Pro、自然 5 小时／一周恢复和长期无人值守没有实账验收。
- 云端区整理官方导出的本地副本，生成待操作清单并打开官方页面；没有云端聊天／记忆自动删除接口，不下载云附件。
- 本机清理先备份校验；归档本身不释放空间，永久清除需要本机确认。缓存按钮仅清除 AI Link 自身 HTTP 资源缓存。
- 自动个人统计观察本机日志；共享日志不能自动识别作者，tokens 不是套餐额度百分比。
- 发行版未代码签名，无安装器或自动更新；未验收所有 SmartScreen 与企业设备策略。

fresh-0.13.0 发行包不带运行状态，首次运行创建独立的新状态与缓存，保留旧版数据。官方对话与账号功能仍需安装并登录官方 Codex CLI。
