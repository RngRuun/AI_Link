# 操作说明

## 网络

启动本机 HTTP／mixed 代理，在传输策略填写一至两个入口，验证后开启接管。备用入口应独立可用；多个端口不叠加带宽。退出恢复此前代理，最小化继续运行；异常时可用发行包的紧急恢复脚本。

## 额度与个人用量

连接 Codex，读取已有对话并接入，保存两项阈值、逐条续聊内容和总开关，再开启守护。创建新的只读任务是可选功能。控制边界和未知结果见 quota-guard.md。

个人曲线自动采集 CODEX_HOME/sessions，默认当前用户的 .codex/sessions，每 120 秒更新，支持立即采集。个人上限按档案与 Plus／Pro 分开。缺失日志及多人共用目录不能证明具体使用者身份。

## 多人用量

新建成员，选择本页自己的 Plus／Pro，再导入 JSONL 或 sessions／年／月／日目录，也可拖放文件。团队只在导入时更新，与个人自动采集独立。重叠区间去重，归属冲突整批拒绝，支持重新归属。报表支持全部、近 5 小时、近 7 天和 CSV／SVG 导出。

## 清理

铜色本机与蓝色云端分区独立。选择时间、工作区和保留类别，核对预览；重要标记排除目标。归档可恢复，永久清除需原生确认。云端导出生成待处理清单，不代表云端删除。详见 storage-cleanup.md。

## 界面

目录卡片和侧栏都可导航；每页顶部有返回目录与文件夹定位。小窗口导航可横向滚动，正文独立滚动。减少动画停止背景、状态呼吸和信号流动；系统减少动画设置同样有效。
