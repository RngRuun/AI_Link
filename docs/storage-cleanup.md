# 存储清理 0.13.0

存储清理是独立工作空间。铜色代表本机，蓝色代表 ChatGPT 云端导出整理；列表、预览、成果和批次按来源隔离。每页的返回目录进入工作空间目录并回到页首，文件夹入口打开明确的数据目录，不执行 shell 命令。

## 本机操作流程

1. 点击扫描，本应用启动独立 Codex app-server，只调用初始化、列表和历史控制，不发模型任务、不要求重新登录。默认 CODEX_HOME，未设置则 ~/.codex；会话、诊断日志与其他状态分开。
2. 用闲置天数、工作区和本机日期范围筛选。重要标记、Codex 固定、额度守护或续聊目标、最近 24 小时更新、派生关系及无法完整读取的项目排除。派生关系保护用于防止官方归档／删除的级联影响。
3. 选择最多 20 项和保留类别，预览显示明确目标与原始字节数；10 分钟有效、一次使用。执行前重新检查保护、完整目录关系、文件哈希与修改时间。
4. 用 thread/resume 获取写入权并核对最后回合完成／中断／失败状态。活动写入者冲突或未知状态拒绝清理；只接受接管自行追加的 thread_settings_applied 元数据事件，新消息或新回合不当作设置变化放行。
5. 先写独立成果并保存 SHA-256 校验的完整原始记录，再写操作意图并调用 thread/archive。日志只处理旧 .log；归档不等于释放磁盘空间。
6. 回收区调用 thread/unarchive 恢复，拒绝覆盖已有新文件或变化的归档。永久清除由主进程先请求清单，原生窗口展示具体名称和影响；取消不发送删除。确认后再检查原始归档与关联关系，调用 thread/delete，成功才移除本批完整恢复备份。保留成果与工作区原文件始终保留。

删除结果未知会标记 delete_pending 并保留备份，不自动重放。归档结果未知可在核实后恢复；不把未知状态显示成成功。存在独立客户端同时改动的服务端竞争时仍可能拒绝操作，没有跨进程原子事务保证。不要在清理期间从其他客户端修改相同对话。

## 保留类别

- 输出文件：仅提取助手消息中的本地 Markdown 文件链接。支持文档、图片、常见代码及数据文件；限制到对话工作区内实际文件，不处理重解析点、符号链接、硬链接、隐藏目录和认证配置。单文件 25 MiB，每对话 100 MiB。不能复制的链接保留状态索引，不能当成附件已下载。工作区所有原文件保留原位。
- 最终答复：有 phase=final_answer 时保留最终阶段答复，旧格式缺失阶段时退回最后一条助手答复。
- 重要结论：从最终答复中提取包含结论、约束、决定、验证、测试、待办等明确词语的段落。此规则不是模型语义分类，需人工核对。
- 代码片段：保留最终答复中的完整 Markdown 围栏代码块。

目录在 %LOCALAPPDATA%/AIExperience/Network/retention/batches/<批次>/<目标哈希>/。preserved/ 是独立成果，original 是完整恢复备份，manifest.json 记录状态。永久清除前打开目录检查，尤其是「仅保留文件」模式。配置、云端索引或批次损坏时停止覆盖相关文件；其他工作空间可以继续使用。

## 缓存范围

可处理 Codex 的旧诊断 .log，和 AI Link 本应用的 HTTP 资源缓存。资源缓存清理由 Electron clearCache 完成，保留 cookies／登录、Local Storage 设置与聊天。不会改写 auth.json、config.toml、SQLite 库、技能、记忆目录、项目文件；没有接入 Codex 原生桌面缓存或服务端模型缓存，也不宣称释放模型上下文或进程 RAM。

## 云端导出整理

原生文件选择器选择官方 ZIP 或 conversations JSON。按账户／分组标签与 conversation ID 生成隔离索引；相同标签同 ID 去重，不同标签分开。只跟随导出的 current_node 分支；没有分支标记而存在分叉时拒绝猜测。源导出包不改写，内容仅在本机处理。

选择保留内容后生成 cloud_pending 清单与本地成果，不修改云端，也不删除原导出与索引。清单通过受限原生入口打开 https://chatgpt.com/c/<ID>，需要用户在官方界面确认归档或删除。没有接入可用的 ChatGPT 云端删除／记忆管理接口。附件仅生成链接索引，当前不从 ZIP 提取附件、不访问附件链接；请先自行下载并验证实际文件。

云端聊天、保存的记忆和 Library 文件具有独立生命周期，不把本地整理或聊天归档当成三者已删除。官方说明：https://learn.chatgpt.com/docs/enterprise/chatgpt-work-cloud-security 。导出分组只是本地标签，不能据此确认真实账户或项目身份。

## 访问与验证

渲染器不能直接传任意导入路径、打开任意 URL、读取本机凭据或绕过原生永久删除确认。IPC 仅接受固定命令，已知目录由后端生成；官方链接需匹配固定来源和路径。诊断报告不导出清理原文、保留成果、云端导出或批次目标。

当前结果见 test-report.md。真实 Codex 联调使用隔离记录与本机模型替身，不清理用户真实聊天。官方协议：https://learn.chatgpt.com/docs/app-server 。
